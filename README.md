# Real Estate Insights Dashboard

## Project Overview

Analyzed regional real estate transactions from 2011–2022 to identify sales trends across towns and property categories.

The project uses Tableau to explore regional sales patterns and present insights through an interactive dashboard and Tableau Story.

## Objectives

- Analyze real estate sales trends across regions and towns
- Compare sales performance across property categories
- Identify geographic and year-wise patterns
- Build an interactive dashboard for exploration and comparison
- Present key findings through a Tableau Story

## Tools & Technologies

- Tableau
- Data Visualization
- Calculated Fields
- Filters
- Parameters
- Highlight Actions
- Dashboard Development

## Analysis & Dashboard

The Tableau dashboard uses calculated fields, filters, parameters, and highlight actions to enable interactive exploration of real estate transactions.

The Tableau Story presents key growth trends and geographic patterns identified during the analysis.

## Project Files

| File | Description |
|---|---|
| `Real_Estate_Insights_Dashboard.twbx` | Packaged Tableau workbook containing the dashboard and analysis |

## Key Outcome

The analysis provides an interactive view of regional real estate sales patterns across towns and property categories, supporting comparison of trends across the 2011–2022 period.
